Interruption Handling

Mid-MONO Interruption

When direction changes during MONO phase, frames are calculated proportionally:

fg_frames_driven = 6 - fg_frames (clamped to 0 if fg_frames >= 6)
fg_frames_2w = (driven == 2) ? 3 : driven (+1 compensation at 2 frames)
fg_frames_2b = driven + 1 (always +1 for black direction)
